# Launch copy pack — how to use it

Five artifacts, one editing rule: **edit for truth, not for polish.** Everything factual I could verify against the repo is already accurate. Anything only you know is marked **[FILL: ...]** — there are about a dozen across the pack. Delete any paragraph that feels false to you; don't add hype to any that feel flat. Flat is the correct register.

| File                    | What it is                                           | Where it goes                                                | When (per launch plan)             |
| ----------------------- | ---------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------- |
| 01-story-post.md        | The canonical "how I built this" post                | gladlabs.io dev diary first, then dev.to with canonical link | Phase 2.3, also linked from README |
| 02-show-hn.md           | Title options + submission text + your first comment | news.ycombinator.com/submit                                  | Phase 2.2, Tue–Thu ~8–10am ET      |
| 03-reddit-localllama.md | Technical post, cross-model QA angle                 | r/LocalLLaMA                                                 | Phase 2.1 — this one goes FIRST    |
| 04-reddit-selfhosted.md | Self-hosting angle                                   | r/selfhosted                                                 | Phase 2.3                          |
| 05-faq-crib-sheet.md    | Pre-written answers for hard comments                | Your phone/private notes. Never posted anywhere.             | Open during every launch day       |

Mechanical notes: HN titles must be ≤80 characters (all options are). Re-read each subreddit's self-promo rules the night before posting — both subs currently tolerate open-source projects presented with technical substance, but rules drift. After the r/LocalLLaMA post, fold whatever questions surprised you into the crib sheet and the HN first comment before launch #2.
